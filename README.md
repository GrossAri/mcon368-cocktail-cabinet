# Cocktail Cabinet

Cocktail Cabinet is a collection of classic arcade games brought together in one interactive browser experience.

The cabinet features **Snake, Breakout, Splat, Asteroids, Missile Command, Imitation**, and an additional game of the player's choice.

What makes the collection different is the ability to **flip the roles**. Instead of always playing the traditional side, players can switch places with the computer. In Snake, for example, the computer controls the snake while the human places the apples. Other games introduce their own variations on this idea, creating new ways to experience familiar challenges.

**Wave 2** expands the cabinet with an eighth, original game featuring its own mechanics and rules, while improving the existing collection with sound, refined gameplay, and a better overall experience.

The goal is a fun, accessible arcade collection that gives familiar games an unexpected twist.
