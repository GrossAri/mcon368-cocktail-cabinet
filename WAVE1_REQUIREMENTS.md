# Wave 1 — The Cocktail Cabinet

**Source:** uploaded Canvas assignment description (snapshot). **Due:** Oct 5, 2026 at 5:55 PM. **Points:** 20. **Submission:** Canvas text entry.

## Build
A single web page with seven games: Snake, Breakout, Splat, Asteroids, Missile Command, Imitation, and one of the student's choice.

Every game must work in normal and flipped modes, permitting a human or computer on either side. Games must be fun, fair, start easy and gradually become harder. Computer opponents must genuinely follow the rules; no scripted wins or skipped collisions.

## Flipped roles
- Snake: human places apples; computer controls snake.
- Breakout: computer plays against human.
- Splat: human lays out columns; computer navigates without cheating.
- Asteroids: computer flies and fires; human sends asteroids.
- Missile Command: design a meaningful flip.
- Imitation: against AI or real person in a separate browser.
- Student-chosen game: design a meaningful flip.

Imitation must connect two browsers for real human interaction. Matchmaking should not connect instantly in a way that reveals an AI opponent.

## Constraints
- Static HTML/CSS/JavaScript application only; a game engine may produce static output, but no custom application server.
- No Anthropic API key. Assignment says AI runs through Claude in the student's browser; investigate rather than inventing an undocumented integration.
- Netlify deployment from GitHub with automatic updates on push, served at a domain/subdomain the student owns (not solely a netlify.app URL).
- Discuss problems/solutions on course Slack; reply to classmates' threads.
- Provide a Claude delegation log with task, output, and actual verification.

## Canvas submission
All three: (1) public custom-domain URL requiring no personal login, (2) GitHub repository URL, (3) delegation log. Repo-only or netlify.app-only does not qualify.

Graded holistically for working, fun games on both sides. Student must explain, trace, and change any submitted code upon request.
